# سامانه شمارش آرای شورای دانش‌آموزی

برنامه دسکتاپ ویندوز با رابط گرافیکی فارسی و کتابخانه‌های استاندارد پایتون.

## اجرا
1. Python 3 را نصب کنید.
2. فایل `student_council.py` را دانلود کنید.
3. در پوشه فایل، ترمینال را باز کنید و اجرا کنید:

```bash
py student_council.py
```

## امکانات
- افزودن نامزد با نام دلخواه
- ثبت رأی برای هر نامزد
- ثبت آرای باطله
- نمایش آرای معتبر و مجموع آرا
- ذخیره خودکار شمارش در فایل JSON
- خروجی CSV و گزارش قابل چاپ
- چیدمان دو ستونه نامزدها

**توجه:** این برنامه برای ثبت و شمارش محلی آراست؛ برای انتخابات رسمی، نتیجه باید طبق مقررات مدرسه و با نظارت مسئولان تأیید شود.
